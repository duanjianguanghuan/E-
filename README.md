# E游周享 - 旅游主题移动应用

一个精美的旅游主题 uni-app x 应用，支持两种界面主题切换。

## 功能特点

- 🎨 **双主题支持**
  - 经典简约主题：干净清爽的传统界面风格
  - 液体玻璃主题：现代磨砂玻璃质感的视觉体验
  
- 📱 **首页功能**
  - 智能问候（根据时间显示不同问候语）
  - 搜索功能入口
  - 快捷导航：景点、美食、住宿、路线
  - 热门推荐卡片展示
  - 近期活动列表

- ⚙️ **设置页面**
  - 主题切换功能
  - 应用信息展示

## 技术栈

- **框架**: uni-app x (Vue 3)
- **语言**: UTS
- **样式**: CSS + SCSS

## 项目结构

```
.
├── App.uvue               # 应用入口组件
├── main.uts               # 主入口文件
├── manifest.json          # 应用配置文件
├── pages.json             # 页面路由配置

```

## 快速开始

### 环境要求

- HBuilderX 3.6+

### 运行项目

1. 使用 HBuilderX 打开项目目录
2. 点击「运行」→「运行到浏览器」或选择其他运行方式
3. 在浏览器或模拟器中预览应用

### 主题切换

1. 点击首页右上角的设置图标
2. 在设置页面中选择「经典简约」或「液体玻璃」主题
3. 主题设置会自动保存

## 文件说明

### composables/useTheme.uts

主题管理模块，提供以下功能：

- `currentTheme`: 当前主题状态
- `isLiquidGlass`: 检测是否为液体玻璃主题
- `isNormal`: 检测是否为经典简约主题
- `setTheme(theme)`: 设置主题
- `toggleTheme()`: 切换主题

### pages/index/index.uvue

首页组件，包含：
- 自定义导航栏
- 搜索栏
- 快捷功能入口
- 推荐卡片（横向滚动）
- 活动列表

### pages/settings/settings.uvue

设置页面组件，包含：
- 主题选择卡片
- 应用信息展示
- 返回导航

## 主题系统

应用采用 CSS 类策略来实现主题切换，通过 `themeClass` 计算属性返回不同的主题类名，所有样式都针对不同主题做了适配。

### 经典简约主题

- 使用明亮清新的配色方案
- 传统卡片式设计
- 白色背景 + 浅灰色阴影

### 液体玻璃主题

- 使用深色渐变背景
- 半透明玻璃效果卡片
- 模糊背景（backdrop-filter）
- 柔和的阴影和发光效果

## 开发说明

### 添加新页面

1. 在 `pages/` 目录下创建新页面文件
2. 在 `pages.json` 中添加页面路由配置
3. 使用 `useTheme()` composable 来获取和设置主题

### 自定义主题

主题样式可以通过修改以下部分进行扩展：
1. 页面文件中的 `.theme-glass` 样式块
2. 全局样式文件 `uni.scss` 中的变量
